# Alien Syntax — design specification

**grammar version:** `3dom-grammar/1.1.0` · **phase:** 2 · **targets:** CHI 2027

---

## What this is

Phase 1 froze 3DOM: two EBNF notations, a terminal inventory with stable IDs, a
matched-complexity table, three conformance corpora at 100% production coverage,
and a scoring policy. Phase 2 builds a language with **maximal measured distance
from pretraining, at matched token cost, that maps to the identical JSON IR.**

The manipulation is confined to **Σ**. The non-terminal set **N** and the shape
of **P** are frozen. Formally there is a bijection φ such that for every
production `A → X₁…Xₖ` in P_3DOM, the production `φ(A) → φ(X₁)…φ(Xₖ)` is in
P_alien with the same sequence order, the same alternation count, the same
placement of `*`, `+`, `?`, and the same arity k.

That is not a claim made in prose. It is a **build property**: the alien grammar
is `template + φ`, and the template is the Phase 1 grammar with its 29
substitutable terminals replaced by slots. Rendering the template with φ = identity
reproduces `3dom_grammar.iso.ebnf` and `3dom_grammar.w3c.ebnf` **byte for byte**,
which is asserted on every render and in `tests/test_invariants.py`.

## The three candidates

| | construct | what it measures |
|---|---|---|
| **α** permuted lexicon | INTERFERENCE | strong priors, all pointing the wrong way |
| **β** pseudo-lexicon | ABSENCE at matched fertility | weak priors, matched token cost |
| **γ** glyph lexicon | SURFACE DISTANCE at unmatched cost | a control, not a primary language |

α and β are **different psychological constructs** and are never pooled into one
"unfamiliarity" scale. See `reports/CANDIDATE_SELECTION.md` §2.

## Design decisions, and the invariant each one satisfies

| Decision | Invariant | Why |
|---|---|---|
| The grammar is `template + φ`; the template is the Phase 1 file with 29 terminal slots | **I1, I2, I3** | N and P are not re-authored, so they cannot drift. The identity render is byte-identical to Phase 1, asserted on every run. |
| φ is keyed on the stable terminal **ID**, never on the surface character | **I7** | `.` serves two roles; a character-keyed rename would break whichever role it did not target. |
| `T_CHAIN_OP` and `T_CLASS_SIGIL` receive **one identical spelling**, enforced by `overload_groups` | **I7** | De-overloading `.` would make the alien language strictly easier to lex — an unmatched complexity change. The loader raises; it does not warn. |
| `T_QUOTE_S` / `T_QUOTE_D` are `substitutable:false` and declared `frozen` | **I8** | Symmetric delimiters carry the quote-agreement constraint repair D2 installed. An asymmetric pair (`‹ … ›`) would delete it structurally. |
| `T_WS` is `substitutable:false` and declared `frozen` | **I9** | The descendant combinator stays whitespace, so significant-whitespace and the two-level parse survive. A visible glyph would remove both. |
| No candidate is prefix, postfix or stack-based; the chain stays infix and left-to-right | **I3, I4** | That is a manipulation of P, a separate factor, and is explicitly out of scope for this phase. |
| No nesting or recursion is introduced; the 52-state DFA still accepts every positive item | **I4** | A finite automaton exists iff the language is regular. |
| Closed sets stay at 15 verbs / 4 types / 2 pseudos / 2 argument kinds, with 21 distinct closed-set spellings | **I5** | Cardinality is a matched-complexity invariant; distinctness prevents a merge from masquerading as a rename. |
| The k = 2 decision point is preserved and tested: after a selector-internal `WS` the automaton still offers both a child and a descendant continuation | **I6** | Lookahead requirement is part of grammatical complexity. |
| Zero ambiguous parses over every alien positive corpus, checked by Earley's explicit-ambiguity mode **and** by an exact derivation counter | **I10** | Two independent witnesses, mirroring Phase 1's gate G6. |
| The negative corpus is generated **by φ**, not rewritten | **I1–I10** | If a 3DOM near-miss stops being a near-miss after substitution, φ moved something structural. All 64 still reject in all three lexicons. |
| `selector.raw` in the IR is re-emitted in the 3DOM reference spelling, never copied from the surface | **isomorphism** | `raw` is required by `ir_schema.json`; if it held surface text the alien IR could never equal the 3DOM IR. |

## The φ-map, as data

```json
{
  "phi_id": "beta",
  "targets_grammar": "3dom-grammar/1.1.0",
  "generated": "…",
  "map": {
    "T_SELECTOR_ENTRY": { "from": "$S",      "to": "&Q" },
    "T_CHAIN_OP":       { "from": ".",       "to": "~"  },
    "T_CLASS_SIGIL":    { "from": ".",       "to": "~"  },
    "T_VERB_RECOLOR":   { "from": "recolor", "to": "flertum" }
  },
  "overload_groups": [["T_CHAIN_OP", "T_CLASS_SIGIL"]],
  "frozen": ["T_WS", "T_QUOTE_S", "T_QUOTE_D", "…"],
  "notes": "…"
}
```

`src/phi.py` validates eight properties and **raises** on any of them —
`PhiValidationError`, never a warning:

| | check |
|---|---|
| V1 | targets the frozen grammar version |
| V2 | every substitutable terminal present exactly once; no extras |
| V3 | no `substitutable:false` terminal is substituted (I8, I9) |
| V4 | each entry's `from` matches `terminals.json` byte-for-byte |
| V5 | overload groups receive one identical spelling (I7) |
| V6 | φ preserves the **spelling partition** — two IDs share an alien spelling iff they share a 3DOM one. This is bijectivity modulo overloads, and it is what makes φ⁻¹ derivable rather than hand-maintained. |
| V7 | the `frozen` list covers every non-substitutable terminal and names `T_WS` and both quotes explicitly |
| V8 | no alien spelling starts with, or contains, a character the two-level lexer already claims |

## A note on Phase 1's collision annotation

`terminals.json` says T_CHAIN_OP and T_CLASS_SIGIL "get INDEPENDENT alien
spellings". The hazard that sentence describes is a φ-map keyed on the
**character** `.` renaming one role and silently breaking the other. This
implementation removes that hazard by keying on the terminal ID: the two roles
carry two **independent map entries**. Invariant I7 additionally requires those
entries to carry the **same value**, because de-overloading `.` would make the
alien language strictly easier to lex than 3DOM.

Both readings are supported by the same machinery. If the stronger reading is
intended — two genuinely different spellings — set `"overload_groups": []` in the
φ-map and give the two entries different values; V5 and V6 relax accordingly and
`test_I7_overload_preserved` is the one test that would need its expectation
flipped. That is the entire cost of the change.

## Known findings, carried forward rather than buried

1. **`|Σq|` cannot be held at 39.** 3DOM's `.` occupies three grammar sites —
   chain operator, class sigil, and the decimal point in `number` — so the
   content-keyed count collapses three roles into one entry. Any φ that renames
   the first two (as it must) while leaving the frozen decimal point (as it must)
   yields 40. This is a metric-definition defect in Phase 1's METRICS.md, not a
   candidate defect; the structural invariant is the **terminal ROLE count (43)**,
   which passes. Full diagnosis and the recommended repair are in
   `reports/METRICS_PARITY.md`. No Phase 1 file has been modified.
2. **No glyph lexicon can be isomorphic.** Identifier values are copied verbatim
   into the shared IR, so `T_IDENT` is frozen ASCII; a non-ASCII word-class
   spelling is therefore disjoint from the identifier charset, and `⍇⍇` reaches a
   token sequence (`TYPE TYPE`) that no 3DOM string can produce. γ's language is a
   strict superset of φ(L(3DOM)). See `reports/CANDIDATE_SELECTION.md` §3 and §5.
3. **EBNF metasyntax is a live hazard for sigil choice.** β's first draft spelled
   the wildcard `?` and the child combinator `|`; `?` delimits an ISO/IEC 14977
   special sequence, which silently swallowed nine productions in the generated
   appendix. Caught by |N| parity, now gated at render time by G-R6, which
   re-parses the generated appendices rather than consulting a blacklist.
4. **`conformance/coverage.py` in Phase 1 does not run as shipped.** It opens
   `"negatives.txt"`; the file is `negative.txt`. Gate G4's success branch also
   prints G5's message, and G6's `else` is attached to the `for` rather than the
   `if`, so its pass line only prints when the loop is empty. The corpora and the
   grammar are unaffected — Phase 2 re-implements the same six gates as A1–A7 in
   `src/generate_corpus.py` and they all pass — but the Phase 1 CI script itself
   needs those three fixes before it can be re-run. Reported, not modified.

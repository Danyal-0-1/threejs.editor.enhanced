# alien_syntax — Phase 2

An alien lexicon for 3DOM with maximal measured distance from pretraining, at
matched token cost, mapping to the identical JSON IR.

**grammar version:** `3dom-grammar/1.1.0` (frozen; Phase 1 is not modified)

The manipulation is confined to **Σ**. N and the shape of P are frozen. The
alien grammar is `template + φ`, and rendering the template with φ = identity
reproduces the Phase 1 `.ebnf` files **byte for byte** — asserted on every render
and in the test suite. 3DOM itself is the φ = identity member of the family, so
the isomorphism tests exercise one code path, not two implementations that happen
to agree.

## Run it

```bash
cd alien_syntax
export PYTHONPATH=src
pip install lark                       # required: the reference parser (Earley, clause P1)

python3 grammar/templates/build_templates.py     # derive templates from Phase 1
python3 grammar/render_grammar.py alpha beta gamma
python3 src/generate_corpus.py alpha beta gamma --winner=beta
python3 measure/collisions.py
python3 measure/dfa_parity.py
python3 measure/metrics_parity.py > reports/METRICS_PARITY.md
python3 tests/test_isomorphism.py && python3 tests/test_roundtrip.py \
  && python3 tests/test_invariants.py
```

Needs models (not run above):

```bash
pip install transformers torch
python3 measure/fertility.py --md            # CONSTRAINT 1
python3 measure/prior_strength.py --md       # the PRIMARY objective
```

`measure/fertility.py --structural --md` runs without models and reports the
character/byte proxy; it is a proxy and is labelled as one.

## Additions beyond the Phase 2 brief

Four files the brief did not name, each because the alternative was to hand-write
something that must not be hand-written:

- `grammar/templates/build_templates.py` — derives the slotted templates from
  Phase 1 mechanically, driven by `terminals.json`'s per-production terminal
  mapping. Hand-slotting two long grammars would have been a transcription risk,
  and the rule that resolves the `.` overload also protects the decimal point for
  free.
- `grammar/templates/grammar.lark.template`, `grammar.diagram.template.md` — the
  brief lists `.lark` and `.diagram.md` under `generated/`, which requires
  templates for them.
- `candidates/gen_beta_lexicon.py` — β's spellings are generator OUTPUT, seeded
  and reproducible, not a hand-picked word list.
- `measure/metrics_parity.py` — `reports/METRICS_PARITY.md` inherits Phase 1's
  "generated, do not hand-edit" rule.

## Findings that need a decision (details in the spec and the reports)

1. `|Σq| = 39` cannot be held by any valid φ — 3DOM's `.` is chain operator,
   class sigil **and** decimal point, and the count collapses three roles into
   one. The structural invariant is the terminal ROLE count (43), which passes.
   Phase 1's METRICS.md needs a row re-definition; no grammar change.
2. No glyph lexicon can be isomorphic to 3DOM, provably — `T_IDENT` is frozen
   ASCII, so non-ASCII word-class spellings make unreachable token sequences
   reachable. γ is a control, not a candidate.
3. `conformance/coverage.py` in Phase 1 does not run as shipped: it opens
   `negatives.txt` (the file is `negative.txt`), G4's pass branch prints G5's
   message, and G6's `else` is attached to the `for` instead of the `if`. The
   grammar and corpora are fine; the CI script needs three fixes. Phase 2
   re-implements the same gates as A1–A7 and they pass.

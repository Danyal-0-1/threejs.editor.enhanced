# Experiment archive

Experiment directories keep immutable evidence from completed runs. Their UTC
timestamp is the canonical directory name; the numbered label is recorded in
each experiment's `EXPERIMENT.md` so captured paths and logs never need to be
renamed.

| Label | Canonical directory | Status | Summary |
|---|---|---|---|
| [Experiment 01](20260901-233702/EXPERIMENT.md) | `20260901-233702` | **CLOSED — NO WINNER** | Phase 1/2 baseline using the original α, β, and γ candidates |

New approaches must use a new timestamped directory. Do not overwrite or append
to a closed experiment.

# ASU RC LLM API: what each model can measure (2026-10-22)

Probed with neutral prompts only, never the experiment's materials (the prompts are in `probe_2026-10-22.json`).

- **Arm A** (margins from a forced prefix, as Phase 3.3 scored them): `/v1/completions` returns every prompt token's id and log-probability with special tokens off, and three test margins could be scored from the first divergent token.
- **margin step**: every test margin was a whole multiple of this. A coarse step means the server rounds its logits (bf16), so margins nearer zero than the step have an unreliable sign; Phase 3.3 avoided this with an fp32 output head, which an API cannot offer.
- **repeatable**: the same request gave the same margin, bit for bit.
- **Arm B** (greedy generation from raw text): `/v1/completions` answered, and twice the same.
- **served id**: the model the gateway actually ran, and its `system_fingerprint`. The pipeline pins this pair and refuses to mix answers from two of them.

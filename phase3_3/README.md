# Phase 3.3 — the results from ASU Sol

The preregistered Phase 3.3 study ran on ASU Sol from 2026-10-06 to 2026-10-09: 21 models,
held-out mappings, two grammar families. This folder holds its results.

| what | where |
|---|---|
| **the results of every Sol run** (development, held-out, setup, smoke), with the later analyses in each run's `analysis_addenda/` | [`sol_results/`](sol_results/README.md) |
| the scripts and logs that ran on Sol outside the repository | [`sol_experiment_root/`](sol_experiment_root/README.md) |
| **the code** | [`../phase3_2/sol/`](../phase3_2/sol/README.md). The pipeline was built inside Phase 3.2's folder, and the development freeze pins it there |
| **the explanations** | [`../explanations/phase3_3/`](../explanations/README.md): the design and math in `sol_experiment_explained/`, the results in `heldout_results_explained/` |
| the first Phase 3.3 run (laptop only), its reports and its errata | [`../archive/phase3_3_first_laptop_run/`](../archive/phase3_3_first_laptop_run/README.md) |

Until 2026-10-22, this folder also held that first run's reports (`00`–`05`, `ERRATA.md`,
`outputs_snapshot/`). They are archived now ([`../MOVES.md`](../MOVES.md)).

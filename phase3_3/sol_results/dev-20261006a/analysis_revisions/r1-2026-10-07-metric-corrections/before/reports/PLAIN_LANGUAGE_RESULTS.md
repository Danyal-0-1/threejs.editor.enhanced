# What this run found, in plain language — `dev-20261006a`

> **Run** `dev-20261006a` · **stage** DEVELOPMENT · **status** COMPLETE
>
> **Confirmatory evidence is possible only in a held-out run after the development analysis is frozen. These results are not confirmatory.**

**The picture.** German *Gift* means *poison*: a fluent English speaker can write a perfectly grammatical German sentence that says something else entirely. Here the model is fluent in CSS and is handed a one-page 3DOM phrasebook; we measure how often the old habit wins anyway.

**How often the habit wins.** With the full translation table in the prompt, the familiar-but-wrong spelling was preferred at **39%–58%** of decision sites across the 16 model×lexicon cells measured.

**Does handing over the table help?** Across 16 cells the average effect of the table was 0.09, 0.15, 0.19, 0.14, 0.14, 0.29, 0.21, 0.16, 0.15, 0.15, 0.11, 0.09, 0.20, 0.33, 0.21, 0.19 nats; in **16 of 16** the interval includes zero — handing over the glossary barely changes what gets written.

**How many examples break the habit?** For sites that start wrong, the Kaplan–Meier median number of clean worked examples is: Qwen2.5-Coder-0.5B/dom: 6.22992 (censored 0.13); Qwen2.5-Coder-0.5B-Instruct/dom: 5.88692 (censored 0.18); Qwen2.5-Coder-1.5B/dom: 5.67693 (censored 0.22); Qwen2.5-Coder-1.5B-Instruct/dom: 3.58495 (censored 0.20). 'Censored' means the habit never broke within the ladder — those sites are kept, not dropped.

**What this does not show.** Nothing here is confirmatory: these are development numbers that set the frozen analysis. The 'does 3D knowledge matter?' question is not identifiable with these materials (sigil and verb candidates occupy disjoint token lengths). H2 is NOT TESTABLE.
